# Задача 2 (Практическо упражнение)

## Условие

[Играта](https://appzaza.com/tile-slide-game) започва с квадратна дъска, състояща се от плочки с номера от 1 до N и една празна плочка, представена с цифрата 0. Целта е да се наредят плочките в съответствие с техните номера. Местенето се извършва, като на мястото на празната плочка могат да се преместят плочки отгоре, отдолу, отляво и отдясно.

На входа се подава число N - броя на плочките с номера (8, 15, 24 и т.н.), число I - индексът на позицията на нулата в решението (при -1 се задава индекс по подразбиране - най-долу в дясно) и след това се въвежда подредбата на дъската.

С помощта на алгоритъма IDA* и евристиката "разстояние на Манхатън" да се изведе:

1. На първия ред - дължината на оптималния път от началото до целевото състояние.
2. На следващите редове - съответните стъпки (left, right, up и down), водещи до решението.

## Бележки

- Не всяка конфигурация на входен пъзел е решима. Проверка за решимост може да бъде извършена по описаните методи на следния [линк](https://www.cs.princeton.edu/courses/archive/spring18/cos226/assignments/8puzzle/index.html). Забележете, че при четни дъски и целево състояние, в което 0-та се намира на първия индекс, правилото за проверка трябва да бъде модифицирано спрямо стандартния алгоритъм. При нерешим пъзел изходът е -1.
- Да се предвиди опция за измерване и отпечатване на времето за намиране на решението (повече подробности са налични в секцията „Автоматично тестване").
- В прикачените файлове са предоставени примерни входно-изходни конфигурации и тестови пъзели, чиято цел е да подпомогнат разработката на домашното, но не изчерпват всички тестове, които ще бъдат използвани при оценяването.
- Имплементация на A* вместо IDA* ще бъде приета, но оценката ще бъде намалена.

## Пример

Вход:

```
8
-1
1 2 3
4 5 6
0 7 8
```

Изход:

```
2
left
left
```

## Автоматично тестване

Използвайте конзолния инструмент FMI AI Judge - CLI System
(страница: https://pypi.org/project/fmi-ai-judge/).

Инструментът е разработен на Python, но поддържа решения на различни езици. Той не компилира, а стартира вече компилирани изпълними файлове или скриптове. Основните езици се разпознават автоматично. Ако вашият не е сред тях, подайте команда изрично чрез `--exec "command {src}"`.

Необходим е Python 3 (препоръчително е отделна виртуална среда с venv).

Инсталация (еднократно):

```bash
pip install fmi-ai-judge
```

При обновяване на версията изпълнете `pip install -U fmi-ai-judge`.

Пускане върху вашето решение:

```bash
judge run --bench path/to/solution.py
judge run --bench -p n-puzzle path/to/solution.py
```

Автоматичното разпознаване гледа името на файла (напр. np, npuzzle, n-puzzle).

### Опционално време в изхода

Първият ред може да съдържа ваше измерване (в милисекунди):

```
# TIMES_MS: alg=<милисекунди>
```

Това време се включва в отчета само ако стартирате с `--bench`.

### Тестове само за време (без пълен изход)

Някои по-големи тестове са само за производителност. При тях инструментът стартира решението с променлива на средата `FMI_TIME_ONLY=1`. Ако засечете `FMI_TIME_ONLY=1`, може да пропуснете печата на пълното решение и по желание да изведете само ред с измереното време (формата по-горе). За останалите тестове изходът трябва да е пълен и коректен.
